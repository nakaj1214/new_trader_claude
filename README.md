# new_trader_claude

株の知識がなくても、**決まったルールどおりに日本株を売買できる**よう、毎日の売買指示を Discord に届けるシステムです。
注文は自分で証券会社のアプリから出します（楽天証券・SBI証券のどちらでも可）。

> ⚠️ 利益は保証されません。このシステムの通知は投資助言ではなく、損失が出ることもあります。
> 過去データでの検証結果は [reports/backtest_latest.md](reports/backtest_latest.md) に出ます（初回は GitHub Actions で「バックテスト」を実行すると作られます）。

## しくみ（初期25万円・毎月5万円の場合）

|  | 積立（資金の8割） | 銘柄売買（資金の2割） |
|---|---|---|
| 最初に入れる額 | 20万円 | 5万円 |
| 毎月入れる額 | 4万円 | 1万円 |
| 買うもの | 全世界株式の投資信託（eMAXIS Slim 全世界株式（オール・カントリー）） | TOPIX100（日本の大型株100社）から最大4銘柄 |
| 売買のしかた | 証券会社の「積立設定」で自動購入。基本的に売らない | 月1回の入れ替え＋値下がり時の売却。**システムが通知** |
| システムの役割 | 推定評価額と配分を月1回報告 | 売買指示・成績記録・見直し判定 |

資金の大部分を、長期で最も再現性が高いとされる「世界株式への積立」に置き、残りで銘柄売買に挑戦する構成です。
銘柄売買で失敗しても全体への影響が小さく、うまくいかなければ積立に寄せる判断も月次レポートで出します。

## 銘柄売買のルール（要点）

1. **月末に入れ替え**: 長期トレンドが上向き（株価が200日平均より上）の銘柄のうち、過去12か月の上昇率が高い順に最大4銘柄を持つ
2. **値下がりしたら売る**: 保有中の最高値から15%下がったら、翌朝売る
3. **相場全体が悪いときは休む**: TOPIX が200日平均より下なら、月末にすべて売って現金で待つ
4. **損失の上限**: 銘柄売買の資金が最高時から20%減ったら、すべて売って3か月休む

ルールの理由と弱点は [docs/strategy.md](docs/strategy.md) を読んでください。

## あなたがやること

| いつ | やること |
|---|---|
| 最初に1回 | [docs/setup.md](docs/setup.md) の手順で、口座・積立・Discord・GitHub を設定（1〜2時間） |
| 通知が来た日の夜〜翌朝9時まで | 通知のとおりに、アプリで売り→買いの順に成行注文 |
| 毎月末まで | 証券口座に5万円を入金（積立4万円は自動、銘柄売買用1万円） |
| 月1回 | 月次レポートを読む（見直しが必要ならそう書かれます） |

通知が来ない日は何もしなくて大丈夫です。売買は月に数回程度の想定です。

## 最初は「模擬運用」

`config/settings.yaml` の `mode: paper` のあいだは、通知に【模擬運用】と付きます。実際には注文せず、通知の流れに慣れてください。
慣れたら GitHub 上でこのファイルを開き `mode: live` に書き換えて保存すると、模擬の記録を残したまま実運用が新しく始まります。

## 構成

```text
config/settings.yaml      金額・ルールの設定（ここだけ編集すればよい）
src/trader/               プログラム本体
  engine.py               1営業日の処理（本番とバックテストで共通）
  strategy.py             売買ルール
  daily.py                毎日の実行と通知
  backtest.py             過去データでの検証
state/portfolio.json      システムが想定している保有・現金（自動更新）
data/universe.csv         売買対象の銘柄一覧（JPXから自動取得）
reports/backtest_latest.md  検証レポート（自動更新）
.github/workflows/        自動実行の設定（毎日・バックテスト・テスト）
docs/                     初心者向け手順・ルール解説・運用メモ
```

運用中の確認方法やトラブル時の対応は [docs/operations.md](docs/operations.md) にまとめています。

## 開発者向け

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest -q                     # 外部通信なしの合成データで検証
ruff check src scripts tests
python scripts/run_daily.py --dry-run   # 保存・通知せずに今日の通知文を表示（要ネット接続）
python scripts/run_backtest.py --sensitivity
```
