# はじめての設定手順

順番どおりに進めれば、株の知識がなくても設定できます。各社の画面名・手数料・受付時間は変わることがあるので、迷ったら公式サイトのヘルプで確認してください。

## 1. 証券口座と NISA 口座を作る

- 楽天証券か SBI証券のどちらか1つでかまいません。
- 申し込みのときに **「NISA口座も同時に開設」** を選びます（税金がかからない口座です）。
- 口座の種類を聞かれたら **「特定口座（源泉徴収あり）」** を選ぶと、NISA 以外で利益が出たときの税金も自動で処理されます。
- 開設には数日〜2週間ほどかかります。

## 2. 積立（資金の8割）を設定する

1. 証券会社のアプリで投資信託 **「eMAXIS Slim 全世界株式（オール・カントリー）」** を検索します。
2. **NISA「つみたて投資枠」** で **毎月4万円** の積立を設定します（クレジットカード積立にするとポイントが付く場合があります）。
3. 最初の **20万円** は、同じ投資信託を **NISA「成長投資枠」でスポット購入（一括購入）** します。

これで積立側は完了です。値下がりしても売らずに続けるのが基本です。システムは月1回、推定評価額を報告します（似た値動きの上場ETF「2559」で推定するため、実際の残高と少しずれます）。

## 3. 銘柄売買（資金の2割）の準備

- 証券口座に **5万円** を入金します。毎月末までに追加で1万円入金します。
- 少額なので **1株から買えるサービス（単元未満株）** を使います。
  - SBI証券: **S株**
  - 楽天証券: **かぶミニ®**（「寄付取引」を使います）
- 楽天証券を使う場合は `config/settings.yaml` の `broker: sbi` を `broker: rakuten` に変えます（通知の注文方法の説明が変わります）。
- **NISA「成長投資枠」で買うか、特定口座で買うか**
  - 成長投資枠: 利益に税金がかかりません（設定は `tax_rate: 0.0` のまま）。ただし損失をほかの利益と相殺できず、1年に買える上限（240万円）があります。今の金額なら上限は気にしなくて大丈夫です。
  - 特定口座: 利益の約20%が税金になります。この場合は `tax_rate: 0.20315` にしてください。
  - どちらを使えるかは証券会社の画面で確認してください。

## 4. Discord で通知を受け取れるようにする

1. Discord（無料）をスマホとパソコンに入れ、アカウントを作ります。
2. 左側の「＋」から **自分だけのサーバー** を作ります。
3. 通知を受けたいチャンネル名の横の歯車 →「連携サービス」→「ウェブフック」→「新しいウェブフック」。
4. **「ウェブフックURLをコピー」** を押します。この URL は人に見せないでください（誰でもあなたのチャンネルに投稿できてしまいます）。

## 5. GitHub に Discord の URL を登録する

1. GitHub でこのリポジトリを開き、**Settings → Secrets and variables → Actions** を開きます。
2. **New repository secret** を押し、Name に `DISCORD_WEBHOOK_URL`、Secret に手順4の URL を貼り付けて保存します。

## 6. 確認用の Web ページ（ダッシュボード）を有効にする

1. GitHub でこのリポジトリの **Settings → Pages** を開きます。
2. **Build and deployment** の **Source** を **「GitHub Actions」** にします（保存ボタンはありません。選ぶだけで反映されます）。
3. Actions タブ →「ダッシュボード更新」→ **Run workflow** で一度実行します。
4. 数分後に **https://nakaj1214.github.io/new_trader_claude/** が開けるようになります。スマホのホーム画面に追加しておくと便利です。

- 毎日の売買判断・バックテストのあと、設定を変えたときに自動で更新されます。
- リポジトリが公開のため、このページも URL を知っていれば誰でも見られます（検索結果には出ないよう設定しています）。

## 7. 過去データでの検証を見る（推奨）

結果の要点はダッシュボードにも表示されます。

1. リポジトリの **Actions** タブ → 左の **「バックテスト（過去データでの検証）」** → **Run workflow**。
2. 10〜20分ほどで終わると、`reports/backtest_latest.md` に結果が保存されます。
3. 「7. まとめ」に、TOPIX（日本株全体）と比べて良かったか悪かったかが書かれます。**TOPIX に負けている場合は、銘柄売買の割合を増やさないでください。**

## 8. 毎日の自動実行を始める

- 次の平日17:30ごろから自動で動き始めます（Discord を登録していなくても、模擬運用はダッシュボードで確認できます。実運用には Discord の登録が必要です）。すぐ試したいときは Actions → **「毎日の売買判断」** → **Run workflow**。
- Discord に「🎉 運用を開始しました」と届けば成功です。最初の通知で、買う銘柄と株数が届きます。

## 9. 通知が来たら（毎回の操作）

1. 通知の **🔴 売り** があれば先に、**🟢 買い** をそのあとに注文します。
2. 注文は **成行**（値段を指定しない）で、**翌営業日の朝9時の取引開始前** までに出します。
   - SBI証券「S株」: 注文した時刻によって約定のタイミングが変わります。注文画面の「約定予定」が翌営業日の寄付（前場始値）になっていることを確認してください。
   - 楽天証券「かぶミニ®」: 「寄付取引」を選びます。
3. 株数は通知のとおりに。翌朝の株価次第で現金が足りなければ、1株少なくしてかまいません。
4. 翌日の夕方に「✅ 約定したとみなした取引」が届きます。システムは始値で約定したものとして計算を続けます（実際と数円ずれても問題ありません）。

## 10. 模擬運用から実運用へ

- 最初は `mode: paper`（模擬運用）です。1〜2か月、通知どおりに「注文するつもり」で流れを確認してください。
- 慣れたら GitHub で `config/settings.yaml` を開き（鉛筆マークで編集）、`mode: live` にして **Commit changes**。
- 次の実行で模擬の記録が `state/paper_until_日付.json` に保存され、設定の開始額（5万円）で実運用が新しく始まります。最初の通知で買う銘柄が届きます。
